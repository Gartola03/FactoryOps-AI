# FactoryOps AI — ML

The `ml/` directory contains the machine-learning experiments, notebooks, datasets, and reusable ML code for FactoryOps AI.

The current ML workflow is:

```text
Dataset
   ↓
Exploratory Data Analysis
   ↓
Feature Engineering
   ↓
Training
   ↓
Evaluation
   ↓
Model
```

The ML project is intentionally separated from the application services. The goal is to experiment with datasets and models first, then integrate the resulting models into FactoryOps services when they are stable enough.

---

## Requirements

* Python 3.12+
* [uv](https://docs.astral.sh/uv/)
* Jupyter Notebook

The ML project uses `uv` to manage its Python environment and dependencies.

---

## Setup

From the repository root:

```bash
cd ml
```

Create the virtual environment and install the dependencies:

```bash
uv sync
```

`uv` creates the local `.venv` environment and installs the dependencies defined in `pyproject.toml`.

You normally do not need to manually activate the virtual environment when using `uv`. Commands can be executed through `uv run`.

For example:

```bash
uv run python --version
```

---

## Install Dependencies

To add a new ML dependency:

```bash
uv add pandas numpy matplotlib scikit-learn statsmodels seaborn
```

For Jupyter:

```bash
uv add jupyter
```

For KaggleHub:

```bash
uv add kagglehub
```

When dependencies are added, `uv` updates:

```text
pyproject.toml
uv.lock
```

For an existing project, install the dependencies from the lock file with:

```bash
uv sync
```

---

## Running Jupyter

Start Jupyter from the `ml/` directory:

```bash
uv run jupyter notebook
```

Then open the relevant notebook under:

```text
ml/notebooks/
```

For example:

```text
ml/notebooks/01_dataset_exploration.ipynb
```

Notebooks are intended for experimentation, exploration, visualization, and prototyping.

Reusable ML logic should eventually be moved into:

```text
ml/src/factoryops_ml/
```

# Dataset

The ML experiments use the **Smart Manufacturing IoT-Cloud Monitoring Dataset**.

**Source:** Kaggle

**Purpose:** Explore and develop predictive-maintenance models using industrial telemetry such as:

* Temperature
* Vibration
* RPM
* Machine operating conditions
* Machine failure information

The dataset is used for:

* Exploratory data analysis
* Feature engineering
* Model training
* Model evaluation

This external dataset is used for ML experimentation. It is separate from the telemetry generated by the FactoryOps machine simulator.

The external dataset provides historical examples that can be used to experiment with predictive-maintenance techniques before integrating a trained model into FactoryOps.

---

# Dataset Setup

Raw datasets are stored locally in:

```text
ml/datasets/raw/
```

Processed datasets can be stored in:

```text
ml/datasets/processed/
```

The dataset files are **not committed to the repository**.

The repository contains the directory structure and instructions required to obtain the dataset, while the actual data remains local.

### Dataset download

The notebook can download the dataset automatically using KaggleHub.

Example:

```python
import kagglehub

dataset_path = kagglehub.dataset_download(
    "OWNER/DATASET"
)

```

Replace:

```python
OWNER/DATASET
```

with the actual Kaggle dataset identifier.

If the dataset requires authentication, configure Kaggle authentication according to Kaggle/KaggleHub's documentation before running the notebook.
